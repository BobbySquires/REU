The following algorithm computes $|B(v,r)|$ in any odd Kneser graph $K(2k+1,k)$ graph for fixed $0 \leq r \leq k$ and $v$. Note that since the Kneser graphs are vertex transitive, the choice of $v$ is irrelevant, that is all $r$-balls in $K(2k+1,k)$ have the same number of elements, regardless of where they are centered.

\begin{enumerate}
\item \textit{Find the size of the overlap $s$.} We apply Lemma 4 to describe the $k$-sets of $[2k+1]$ that are distance $r$ from $v$. If $r$ is odd, then for any node $x$ that is distance $r$ from $v$ we have
\[
r = d(v,x) = 2s + 1 \quad \exists s \in \mathbb{Z}_+
\]
\[
\implies \frac{r-1}{2} = s.
\]
If $r$ is even then for any node $x$ that is distance $r$ from $v$ we have
\[
r  = d(v,x) = 2(k-s) \quad \exists s \in \mathbb{Z}_+
\]
\[
\implies k - \frac{r}{2} = s.
\]

\item \textit{Count $k$-sets of $[2k+1]$.} Next we find the number of $k$-sets of $[2k+1]$ that overlap the set corresponding to $v$ in exactly $s$ places. This can be described combinatorial in two steps:
\begin{itemize}
\item Count the number of ways to choose $s$ elements in the $k$-set $v$ to be the overlapping elements. This is $\binom{k}{s}$.
\item Count the number of ways to choose $k-s$ elements of the $k$-set $x$ to not overlap the original set $v$. This is $\binom{2k+1-k}{k-s}$
\end{itemize}
Multiplying gives the formula
\[
\binom{k}{s} \binom{k+1}{k-s} = |\partial B(v,r)|.
\]

\item \textit{Iterate.} Repeat steps $1$ and $2$ for $r' = r-1$ until termination at $r = 0$. Then because
\[
B(v,r) = \bigsqcup_{l=0}^r \partial B(v,l)
\]
we can sum the size of the layers to get
\[
|B(v,r)| = \sum_{l=0}^r \partial B(v,l).
\]

\end{enumerate}

Now we will give an explicit function to find the size of the boundary of an $l$-ball in $K(2k+1,k)$. We drop the vertex from here on due to vertex transitivity. We will use the formula for the number of $k$-sets of $[2k+1]$ that intersect another $k$-set in $s_r$ places, which is the boundary of an $r$-ball
\[
\binom{k}{s_r} \binom{k+1}{k-s_r} = |\partial B(r)|,
\]
as well as the inverse of the distance formula to solve for $s$ in terms of $r$.
\[
s(r) =
\begin{cases}
    k - \dfrac{r}{2}, & r \text{ even} \\[6pt]
    \dfrac{r-1}{2}, & r \text{ odd}
\end{cases}
\]
Plugging the latter into the former gives
\[
|\partial B(l)| =
\begin{cases}
    \dbinom{k}{k - l/2} \dbinom{k+1}{k - (k - l/2)} & l \text{ even} \\[6pt]
    \dbinom{k}{(l-1)/2} \dbinom{k+1}{k - (l-1)/2} & l \text{ odd}
\end{cases}
=
\begin{cases}
    \dbinom{k}{k - l/2} \dbinom{k+1}{l/2} & l \text{ even} \\[6pt]
    \dbinom{k}{(l-1)/2} \dbinom{k+1}{k - (l-1)/2} & l \text{ odd}
\end{cases}.
\]
Using symmetry of binomial coefficients\footnote{$\dbinom{k}{j} = \dbinom{k}{k-j}$} in the even case gives
\[
|\partial B(l)| =
\begin{cases}
    \dbinom{k}{l/2} \dbinom{k+1}{l/2} & l \text{ even} \\[6pt]
    \dbinom{k}{(l-1)/2} \dbinom{k+1}{k - (l-1)/2} & l \text{ odd}
\end{cases}.
\]
We can apply symmetry a second time in the odd case
\[
\binom{k+1}{k - (l-1)/2} =
\binom{k+1}{(k+1) - ( k - (l-1)/2)} =
\binom{k+1}{k+1 - k + (l-1)/2}
\]
\[
= \binom{k+1}{1 + (l-1)/2} = \binom{k+1}{(l+1)/2}.
\]
Now we can write our formula
\[
|\partial B(l)| =
\begin{cases}
    \dbinom{k}{l/2} \dbinom{k+1}{l/2} & l \text{ even} \\[6pt]
    \dbinom{k}{(l-1)/2} \dbinom{k+1}{(l+1)/2} & l \text{ odd}
\end{cases}
\]
or we can simplify the even and odd cases into one using that
\[
\lceil l/2 \rceil = \lfloor l/2 \rfloor = l/2 \quad \text{when $l$ is even},
\]
\[
\lceil l/2 \rceil = (l+1)/2, \quad \lfloor l/2 \rfloor = (l-1)/2 \quad \text{when $l$ is odd},
\]
therefore we can rewrite as
\[
|\partial B(l)| = \binom{k}{\lfloor l/2 \rfloor} \binom{k+1}{\lceil l/2 \rceil},
\]
and the full ball size is therefore
\[
|B(r)| = \sum_{l=0}^{r} \binom{k}{\lfloor l/2 \rfloor} \binom{k+1}{\lceil l/2 \rceil}.
\]
